# Ariel Shirk

Personal site for Ariel "Lemur" Shirk. Plain HTML, CSS, and a little JavaScript, with no build step.

- `index.html`, `styles.css`, `script.js`: the site. It has two modes switched from the nav: day ("Ariel", a field guide) and night ("Lemur", cyberpunk). Add `?mode=night` to a link to open it in night mode.
- `resume.html`: print-friendly résumé; `Ariel-Shirk-Resume.pdf` is generated from it (open in a browser and print to PDF to refresh)
- `images/`: photos, resized with metadata removed

To preview, open `index.html` in a browser. To publish with GitHub Pages, go to Settings → Pages and deploy from the branch root.
